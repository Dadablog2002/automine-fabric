# AutoMine (Fabric 1.16.5)
Client-side mod that digs out a cuboid region.
K opens the menu. Set corner 1 / corner 2 (block you look at), press Start mining.
Opening the inventory/chat only pauses it. Mining and walking speed are vanilla.
Build: push to GitHub -> Actions -> build -> Artifacts. Needs Fabric API 0.42.0+1.16.
