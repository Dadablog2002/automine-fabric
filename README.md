# AutoMine (Fabric 1.16.5)
Клієнтський мод, що викопує прямокутний регіон (куб).
Клавіша K (змінюється в керуванні) відкриває меню: постав кут 1 і кут 2 (блок, на який дивишся), натисни "Почати копання".
Інвентар чи чат лише ставлять копання на паузу. Швидкість копання та ходьби ванільна.
Збірка: push на GitHub -> Actions -> build -> Artifacts. Потрібен Fabric API 0.42.0+1.16.
